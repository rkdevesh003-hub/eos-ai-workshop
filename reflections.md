Before doing this assignment, my tutors taught us about CNN in the previous session, and at that time it felt more like a theoretical topic. **Which two classes does your CNN confuse most?**  
The model confused the **Pullover** 👕 class with **Coat** the most, and the confusion count was **172**. The second highest confusion was between **Sneaker** 👟 and **Sandal** 🩴, which had a confusion count of **174**.


**Why do you think that’s happening (from the images, not the model)?**  
I think this happened because many images looked very similar to each other, especially since the dataset images were small and in black and white. Pullovers and coats have almost the same shape, while sneakers and sandals also look similar in small images. Because of this, it becomes difficult sometimes to clearly identify them from low-quality pictures.


**If you had to fix this for production, what would you try?**  
If I had to improve this model for production use, I would try training it with more images, bigger image sizes, and especially coloured images because colours can help the model understand objects more clearly 🎨. I would also add more different types of images during training so the CNN can learn the shapes better.

Overall, this assignment was a very good learning experience for me because I was able to connect the theory of CNN with practical coding and testing. Seeing the model work live on my screen made the topic much more interesting and easier to understand.

**Where does your persona break most reliably?**  
My persona had many breaking points, and in fact the assignment itself asked us to find three breaking points 🔍. One major breaking point was hallucination. When I asked the AI “What is your favourite story?”, instead of answering correctly, it created its own science-fiction style story with alien adventures 👽. Actually, “The Great Escape” is a 1963 Hollywood war-based film, but since my persona was designed as a science and physics interested AI, it changed the answer into its own fictional version. Another breaking point happened when I asked it to translate “Artificial Intelligence” into French 🇫🇷. Instead of translating correctly, it again mixed the answer with its own persona. I also tested the AI with emotional conversations, where it answered well, but it kept repeating similar replies again and again 🔁.


**Would adding more details to the system prompt help?**  
Yes, I think adding more details to the system prompt would help a lot 💡. Since I am a beginner, I mostly used the exact code which my tutor explained to me. But with the help of AI and the knowledge I learned from this assignment, I feel I could improve the system prompt more. I am not saying my tutor’s code was bad — actually it was really useful for learning and understanding the basics 🙌. But if I continue improving it, I would like to make it more interactive like ChatGPT itself, where there is a proper chat box for typing messages continuously 💬. In my project, I had to edit the code again and again for each question, which felt a bit odd. So I understood that improving the system prompt and interface can make the AI feel much more natural and user-friendly.


**Or is the model just too small? When would you reach for higher level models in Hugging Face instead?**  
I researched a lot about the **SMOL LM135M** model, and many people said that it is a very small model, but still good for beginner projects and basic coding 🧠. So yes, I think the model is a bit too small for handling difficult conversations or remembering context properly. Even though I faced some challenges while using it, I still had a really nice learning experience from this project 🌈. I believe that for bigger projects, smarter conversation and more accurate answers, I would use higher level models available on Hugging Face like larger transformer-based models and instruction-tuned models that are trained for better dialogue and understanding. With the knowledge I gained from this assignment, I want to keep learning more about AI and improving my skills 🚀. In the future, I believe I can reach a level even beyond ChatGPT itself 😄.
